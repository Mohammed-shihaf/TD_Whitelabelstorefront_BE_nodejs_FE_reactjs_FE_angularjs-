# TD_Whitelabelstorefront_BE_nodejs_FE_reactjs_FE_angularjs-

White-Label / Multi-Tenant Storefront: one Node.js (Express) backend
resolves tenant identity from a header and returns tenant-scoped
config; self-serve tenants get a React storefront, enterprise tenants
get an Angular storefront.

See ARCHITECTURE.txt for build commands and the full architecture.

Branches: `whitelabelstorefront_BE_nodejs<18|20|22|24>_FE_reactjs<18|20|22|24>_FE_angularjs<16|17|18|19>`
(64 combinations of Node.js × React × Angular versions).
